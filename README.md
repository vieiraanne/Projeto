# 💻 Portfólio — Anne Vieira Rodrigues

 Este projeto consiste em uma página de **portfólio pessoal** desenvolvida com HTML5. A página apresenta informações sobre a desenvolvedora, suas habilidades, projetos realizados e um formulário para contato.

 ## 📌 Sobre o Projeto

 O portfólio foi criado como parte dos estudos em **Desenvolvimento de Sistemas no SENAI**, com o objetivo de praticar a estruturação de páginas utilizando HTML5 semântico.

 A página contém:

 - Apresentação pessoal;
- Lista de habilidades;
- Tabela com projetos;
- Tecnologias utilizadas em cada projeto;
- Status dos projetos;
- Formulário de contato.

 ## 🛠️ Tecnologias Utilizadas

 - **HTML5**
- **CSS3** — previsto para estilização e responsividade
- **JavaScript** — utilizado em alguns dos projetos apresentados
- **PHP** — definido como destino do formulário (`processar.php`)

### 📩 Entre em Contato

 A página possui um formulário para que visitantes possam enviar mensagens.

 O formulário possui os seguintes campos:

 - **Nome**
- **E-mail**
- **Assunto**
- **Mensagem**

 O envio é realizado utilizando o método `POST` para o arquivo `processar.php`.

 ## 🚀 Como Executar

 1. Baixe ou clone este projeto.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador, como Google Chrome, Microsoft Edge ou Firefox.

 Para que o formulário seja processado corretamente, será necessário ter o arquivo `processar.php` configurado em um servidor com suporte a PHP.
